The Backstory & Problem

Why Traditional LMS Binary Grading Fails

Traditional LMS

  • Treats wrong answers as simply incorrect (0/1 binary grading).
  • No insight into what concept the learner misunderstood.
  • Showing the correct code promotes rote copying, not genuine learning.
  • Fails to differentiate when two students make different mistakes leading to similar wrong outputs.

Re:Learn Paradigm

  • Identifies the underlying mental misconception in the student's mind.
  • Differentiates between different root causes for similar buggy outputs.
  • Generates multimodal interventions (analogies, visual diagrams, rules of thumb).
  • Validates resolution with transfer challenges to guarantee true understanding.
System Architecture

End-to-End Diagnostic Pipeline

1. Code Submission

Student writes Python code for an introductory challenge.

2. AST Feature Extractor

Extracts syntactic trees, slice bounds, operators, and loop scopes.

3. Misconception Engine

Pure-Python TF-IDF centroid classifier predicts 1 of 8 misconception classes.

4. Differentiation

Isolates distinct cognitive faults behind similar wrong outputs.

5. Adaptive Intervention

Delivers analogies, visual diagrams, and corrective diffs.

6. Learner Model & Gate

Validates transfer question to confirm misconception resolution.

Hackathon Key Feature

Misconception Differentiation Showcase

Problem: Extract first 2 elements of [10, 20, 30, 40]. Expected: [10, 20]

Student A: arr[1:2] -> [20]

1-Based Indexing Assumption (M1)

Cognitive Flaw: Believes sequence items count starting from 1 instead of 0, so element #1 is at index 1.

Student B: arr[0:1] -> [10]

Inclusive Stop Bound Assumption (M2)

Cognitive Flaw: Started correctly at 0, but assumed the stop index in [start:end] includes index 'end'.
