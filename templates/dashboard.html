Learner Model Architecture

Cognitive Tracking
1. Cognitive Persistence Tracking:

Counts occurrences of recurring misconceptions per student. If a student triggers the same category more than twice, intervention depth automatically escalates to a visual diagram.

2. Resolution Verification Gate:

Unlike traditional platforms that mark an answer correct if the student merely retries the same question, Re:Learn presents an unseen transfer question to guarantee the mental model is fixed.

3. Mastery Formula:
Mastery % = (Verified Transfer Resolutions / Total Interventions) × 100
